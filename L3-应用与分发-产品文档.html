L3 应用与分发 — Products & Sites

直接面向终端的产品集：Reader（人用的阅读工作流）、Agent API / MCP（机器用的策展接口）、Newsletter。它们消费下层（L0–L2）已 COMPLETED 的判断结果，只负责体验、分发与商业化，并且可以"跨站"——多个垂直站共享同一平台。

层级：L3 客户：开发者(人) + Agent(机器) 商业：Free / Pro · USD 北极星：深度阅读闭环率

1是什么

L3 是平台价值的"变现出口"。它把 L2 的判断结果转化为人能用的产品和机器能调的接口。同一份判断，两种消费：人在 Reader 里读，Agent 通过 API/MCP 调。

3它的客户：人 + 机器

👤 人（开发者）

  • 在 Reader 浏览公共精选、读个性化早报
  • 用 AI 伴读快速理解长文/英文
  • 订阅 Pro 获得个性化工作流

🤖 机器（Agent）

  • 在 Cursor/Claude 里问"今天 AI Coding 值得读什么"
  • 自建 Agent 调 /v1 获取结构化策展结果
  • 把高质量内容上下文喂进自己的工作流

5Agent API / MCP

第二曲线，面向开发者与 Agent 生态，是差异化卖点。

  • 稳定原语：/v1/today · /v1/search · /v1/items/:id · /v1/trending · /v1/sources。
  • MCP 工具：bestpick_today / search / analyze / trending，npx 一键装。
  • 跨站：/v1?vertical= 一个接口服务所有垂直站。

  • 有限 AI 伴读
  • 作用：建立信任、SEO 获客

开发者侧：Public API/MCP 按用量/订阅分层（免费档→开发者→商用），作为第二曲线收入。

8跨站

L3 是"可跨站"的那一层。每个垂直对应一个 L3 站点（CodePick = AI Coding 站），共享 L0–L2 平台。未来加垂直只需起一个新站 + 配一个 L2 lens。Public API/MCP 则天然跨站，一个接口按 vertical 服务全部。

9边界：L3 不做什么

  • 不重算判断：评分/推荐来自 L2，L3 只消费与展示。
  • 不做内容理解/抓取——L0/L1。
  • 不把未 COMPLETED 内容对外。
  • 不泄漏内部推荐决策与隐私上下文给对外 API。
